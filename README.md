# Zeno Network Token – Public Privacy Policy

This repository contains public privacy-policy documents for the Zeno Network Token mobile application.

- [Privacy policy](https://ishfaq176.github.io/ZENO-NETWORK-TOKEN-APP/)
- [Markdown policy](privacy-policy.md)

Only public policy documents belong in this repository. Never commit signing keystores, passwords, private keys, service-account credentials, or other secrets here.

## Project consolidation

The Android application source, signed-AAB workflow and a complete copy of these
policy documents are maintained in the owner's private
[`zeno-network-app-studio-data-` repository](https://github.com/Ishfaq176/zeno-network-app-studio-data-).
This public repository is only the hosting mirror for the existing privacy URL;
it is not a duplicate Android app project.

Policy sources were consolidated on 17 November 2026 under `docs/public-policy/`
in the main app repository. Retain this public host until a replacement public
policy URL is deployed and every store listing and existing link is migrated.
The private app repository cannot host a public Pages site on the current plan.
